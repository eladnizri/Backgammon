# שש-בש — עם מאמן אישי 🎲

אפליקציית ווב של שש-בש קלאסי נגד המחשב, בעברית מלאה (RTL), עם **דירוג אוטומטי של כל מהלך**: בסיום כל תור מופיע כרטיס עם ציון (0–100), הסבר מילולי, והמהלך המומלץ במקרה של טעות. בסוף המשחק מוצג ציון כולל וסיכום המהלכים לשיפור.

הממשק בנוי קודם כול לטלפון: הלוח מותח את עצמו לשטח הפנוי בפועל, ולכן הוא מאונך במסך של טלפון ורוחבי במסך גדול.

## הפעלה

אין צורך בבנייה או בשרת — פותחים את `index.html` בדפדפן:

```bash
open index.html          # macOS
xdg-open index.html      # Linux

# או שרת מקומי
python3 -m http.server 8000   # ואז http://localhost:8000
```

## תכונות

- **שש-בש קלאסי** — חוקים מלאים: חובת שימוש בשתי הקוביות, חוק הקובייה הגבוהה, כניסה מהבר, הכאות, הורדה מהלוח, וזיהוי מארס/מארס טורקי. ללא קוביית הכפלה.
- **שלוש רמות קושי** — קלה, בינונית (היוריסטיקה מלאה) וקשה (expectimax בעומק פליי אחד).
- **דירוג כל מהלך** — המנוע משווה את המהלך שלך לכל המהלכים האפשריים באותה זריקה ומדרג לפי הפרש ההערכה. מהלכים כפויים מזוהים ואינם נספרים בממוצע.
- **הסברים בעברית** — "פספסת הזדמנות להכות", "המהלך משאיר חשיפה גבוהה" ועוד, כולל הצגת המהלך המומלץ.
- **ציון כולל** — בסוף המשחק (ובלחיצה על צ'יפ הציון בכל שלב): ציון ממוצע, התפלגות דירוגים ורשימת המהלכים לשיפור.
- **צליל ורטט** — אפקטים מסונתזים בדפדפן, ניתנים לכיבוי.

## איך משחקים

התור מתקדם מעצמו ודורש כמה שפחות לחיצות:

- **הטלה** — לחיצה על כפתור הקוביות, או לחיצה בכל מקום על הלוח.
- **הזזה** — לחיצה על חייל מסומן. אם יש לו יעד יחיד הוא זז מיד; אחרת מוצגים היעדים ובוחרים אחד. אפשר גם לגרור.
- **שתי קוביות בבת אחת** — גרירה או לחיצה ישירות ליעד הרחוק מזיזה את אותו חייל בשתי הקוביות.
- **הורדה מהלוח** — לחיצה או גרירה אל פס ההורדה שברצועת השחקן.
- **סיום תור** — אוטומטי כשכל הקוביות נוצלו. כל עוד נותרה קובייה אפשר ללחוץ **בטל**.
- **תור כפוי** — כשיש רק מהלך אחד חוקי המשחק משחק אותו לבד.

## איך עובד מנוע הדירוג?

היוריסטיקה מעריכה כל עמדה ביחידות "פיפ" משוערות ומשקללת:

- מצב המרוץ (ספירת פיפ) וחיילים שהורדו
- חיילים חשופים — לפי מספר זריקות היריב שפוגעות (מתוך 36) ועלות ההכאה
- נקודות בנויות לפי חשיבות (נקודת הזהב, נקודת הבר, הבית), אורך החומה ועוגנים
- חיילים על הבר מול חוזק הבית של כל צד, ופיזור ערימות

הציון נגזר מהפער בין המהלך שנבחר למהלך הטוב ביותר: `100 − 3.5 × הפער`.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/rules.js` | ייצוג מצב, מהלכים חוקיים, יצירת כל התורות האפשריים |
| `js/engine.js` | הערכת עמדות, ספירת "יריות", AI בשלוש רמות, דירוג והסברים |
| `js/app.js` | פריסת הלוח, אנימציה, גרירה ולחיצה, זרימת המשחק וסיכומים |
| `style.css` | מערכת העיצוב, הלוח, החיילים והקוביות |
| `tests/run-tests.js` | בדיקות ליבה לחוקים ולדירוג |

### שלושה עקרונות בקוד הממשק

1. **חייל = אלמנט DOM קבוע.** הרינדור משייך מחדש 15 אלמנטים לכל צבע לפי המיקום הקודם שלהם, ולכן מהלך נראה כתנועה רציפה ולא כקפיצה.
2. **הגאומטריה נגזרת מהמידות בפועל.** `fitBoard()` מודד את השטח הפנוי, קובע את יחס הצלעות ומעדכן את `GEO.AR` — אותו קוד משרת לוח מאונך ולוח רוחבי.
3. **המצב מנוהל בשלבים.** `Game.phase` קובע מה מותר בכל רגע; `Game.gen` מבטל טיימרים ישנים אחרי "משחק חדש".

## הערות משחקיות

- השחקן הוא תמיד לבן, נע מנקודה 24 אל הבית (נקודות 1–6, ברביע הימני-תחתון).
- מספרי הנקודות על הלוח הם מנקודת מבט השחקן, וכך גם תיאורי המהלכים.
- בגרירה מקוצרת ליעד של שתי קוביות, אם קיימים שני מסלולים — נבחר המסלול שמכה יותר חיילים. להכוונה מדויקת אפשר תמיד להזיז קובייה-קובייה.
