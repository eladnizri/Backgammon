# שש-בש — עם מאמן אישי 🎲

אפליקציית ווב של שש-בש קלאסי נגד המחשב, בעברית מלאה (RTL), עם **דירוג אוטומטי של כל מהלך**: אחרי כל תור מופיעה הודעה עם ציון (0–100), הסבר מילולי על איכות המהלך, והמהלך המומלץ במקרה של טעות. בסוף המשחק מוצג ציון כולל וסיכום המהלכים לשיפור.

## הפעלה

אין צורך בבנייה או בשרת — פשוט פותחים את `index.html` בדפדפן:

```bash
# אפשרות 1: לפתוח ישירות
open index.html          # macOS
xdg-open index.html      # Linux

# אפשרות 2: שרת מקומי
python3 -m http.server 8000   # ואז http://localhost:8000
```

## תכונות

- **שש-בש קלאסי** — חוקים מלאים: חובת שימוש בשתי הקוביות, חוק הקובייה הגבוהה, כניסה מהבר, הכאות, הורדה מהלוח, וזיהוי מארס/מארס טורקי. ללא קוביית הכפלה.
- **משחק נגד המחשב** — שלוש רמות קושי: קלה, בינונית (היוריסטיקה מלאה) וקשה (expectimax בעומק פליי אחד).
- **דירוג כל מהלך** — המנוע משווה את המהלך שלך לכל המהלכים האפשריים באותה זריקה, ומדרג לפי הפרש ההערכה: מצוין / טוב מאוד / טוב / סביר / לא מדויק / טעות / טעות חמורה. מהלכים כפויים מזוהים ולא נספרים בממוצע.
- **הסברים בעברית** — "פספסת הזדמנות להכות", "המהלך משאיר חשיפה גבוהה", "היה עדיף לבנות נקודה" ועוד, כולל הצגת המהלך המומלץ.
- **ציון כולל** — בסוף המשחק (ובלחיצה על צ'יפ הממוצע בכל שלב): ציון ממוצע, התפלגות דירוגים ורשימת המהלכים לשיפור.
- **ממשק נוח** — לוח בעיצוב עץ קלאסי, גרירה או לחיצה (עובד גם במובייל), הדגשת מהלכים אפשריים, גרירה מקוצרת של שתי קוביות בבת אחת, כפתור ביטול בתוך התור, ומוני פיפ חיים.

## איך עובד מנוע הדירוג?

היוריסטיקה מעריכה כל עמדה ביחידות "פיפ" משוערות ומשקללת:

- מצב המרוץ (ספירת פיפ) וחיילים שהורדו
- חיילים חשופים — לפי מספר זריקות היריב שפוגעות (מתוך 36) ועלות ההכאה
- נקודות בנויות לפי חשיבות (נקודת הזהב, נקודת הבר, הבית), אורך החומה ועוגנים
- חיילים על הבר מול חוזק הבית של כל צד, ופיזור ערימות

הציון נגזר מהפער בין המהלך שנבחר למהלך הטוב ביותר: `100 − 3.5 × הפער`.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/rules.js` | ייצוג מצב, מהלכים חוקיים, יצירת כל התורות האפשריים |
| `js/engine.js` | הערכת עמדות, ספירת "יריות", AI בשלוש רמות, דירוג והסברים |
| `js/app.js` | רינדור הלוח, גרירה ולחיצה, זרימת המשחק, טוסט וסיכומים |
| `style.css` | עיצוב העץ, החיילים, הקוביות וההודעות |
| `tests/run-tests.js` | בדיקות ליבה לחוקים ולדירוג |

## בדיקות

```bash
node tests/run-tests.js
```

## הערות משחקיות

- השחקן הוא תמיד לבן, נע מנקודה 24 אל הבית (נקודות 1–6, למטה מימין).
- מספרי הנקודות על הלוח הם מנקודת מבט השחקן, וכך גם תיאורי המהלכים.
- בגרירה מקוצרת ליעד של שתי קוביות, אם קיימים שני מסלולים — נבחר המסלול שמכה יותר חיילים. להכוונה מדויקת אפשר תמיד להזיז קובייה-קובייה.
